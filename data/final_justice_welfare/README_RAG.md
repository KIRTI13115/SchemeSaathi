# Justice & Welfare RAG source folder

This folder stages five PDFs copied from `data/raw/justice_welfare`. The source downloads already present in the project were preserved; their publication dates and originating URLs have not been verified here. Check the first pages and source/version before treating them as authoritative.

- `Mission_Vatsalya_Guidelines_existing.pdf` — existing Foster Care / Mission Vatsalya PDF
- `Nari_Adalat_SOP_existing.pdf` — existing Nari Adalat PDF

- `Junior_Advocates_Stipend_existing.pdf` — existing junior advocate stipend PDF
- `Gaura_Shakti_existing.pdf` — existing Gaura Shakti PDF

## Official source manifest

`source_manifest.csv` records candidate authoritative links for additional documents. Rows marked `not_downloaded` are URLs only, not files in this folder. Government hosts were unreachable from the current environment during this task, so those PDFs could not be fetched. Prefer the latest dated official notification or guideline linked for each scheme. Avoid indexing old calls for applications as current eligibility rules.

The list intentionally flags duplicates and entries that are activities, statutes, awards, or not a distinct benefit scheme. Do not treat an India.gov category count as proof that every item has a standalone scheme PDF.
